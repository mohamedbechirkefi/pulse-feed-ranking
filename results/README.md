# results/

Machine-readable outputs written by `pulse.cli run` (result schema `pulse.run_result` 1.0.0, one JSON per run under `runs/`, a `set_manifest.json` and `result_schema.json` per set). `pulse.cli report` adds `report/` (metrics.csv, summary.csv, contrasts.csv, FIG-X*.svg, report.md, report.typ, report.pdf), regenerated from the run files.

- `exploratory/`: **exploratory only, not findings.** Runs made before the protocol freeze, with seed ranges disjoint from every confirmatory seed. Committed because they are small and document the planning values in `research/decision_log.md` D-008.
- `raw/`: confirmatory outputs (git-ignored, regenerated by script). Empty: no confirmatory run exists; the runner refuses one until the owner freezes the protocol.
