## Registered experiments

See `research/experiment_registry.csv`: EXP-001 (static, exposure entropy, 480 runs), EXP-002 (drifting, preference reinforcement, 480), EXP-003 (sensitivity: pool skew and choice sharpness, 240), EXP-004 (second test on MovieLens-derived preferences, 60). All frozen (owner-approved 2026-11-24); confirmatory runs complete 2026-11-25; reports written (D-015). EXP-005 (like-rate dependence of the primary contrast): registered 2026-11-25, not frozen (D-018); protocol and config draft with six open parameters; no run before the owner's G-FREEZE word. The demo shows it as registered, not run.

## Scope cuts if the five-day target is threatened (in order)

1. Demo reduced to a minimal static page with precomputed results.
2. EXP-003 tau factor dropped (pool-skew factor kept: it is the invalidation test).
3. EXP-002 drift-form check reduced to one alpha_0 level.
Controls, reports and evidence checks are never cut.
